### 1.2 表结构设计原则

**通用规范**：
- 表名格式：`{模块前缀}_{业务名}`（如 `demo_student`）
- 主键统一：`id`（`BIGINT AUTO_INCREMENT`）
- 审计字段：`create_time`、`update_time`、`create_by`、`update_by`
- 软删除标志：`del_flag`（可选，根据业务需求）

**索引策略**：
- 主键自动创建聚簇索引
- 查询字段建议创建普通索引
- 外键字段建议创建索引
- 状态、类型等区分度低的字段谨慎创建索引

**字符集**：
- 数据库：`utf8mb4`
- 排序规则：`utf8mb4_general_ci`

## 2. API 接口设计

### 2.1 设计原则

- 遵循项目 [API 设计规范](../api-design.md)
- RESTful 风格
- 统一响应格式：
  - 列表：`TableDataInfo`
  - 操作结果/单个对象：`AjaxResult`

### 2.2 接口清单

#### 2.2.1 CRUD 模板（单表）- 8 个标准接口

| 功能 | 方法 | 路径 | 权限标识 | 说明 |
|------|------|------|---------|------|
| 查询列表 | GET | `/{module}/{resource}/list` | `{module}:{resource}:list` | 分页查询 |

| 新增 | POST | `/{module}/{resource}` | `{module}:{resource}:add` | 新增 |
| 修改 | PUT | `/{module}/{resource}` | `{module}:{resource}:edit` | 修改 |
| 删除 | DELETE | `/{module}/{resource}/{ids}` | `{module}:{resource}:remove` | 批量删除 |
| 导出 | POST | `/{module}/{resource}/export` | `{module}:{resource}:export` | Excel 导出 |
| 下载模板 | POST | `/{module}/{resource}/importTemplate` | `{module}:{resource}:importTemplate` | 导入模板 |
| 导入 | POST | `/{module}/{resource}/importData` | `{module}:{resource}:import` | 批量导入 |

## 4. 数据迁移脚本

### 4.1 迁移脚本规范

**命名规范**：
```
V{版本号}__{描述}.sql
```

**示例**：
```
V1.0__init_schema.sql         # 初始化数据库结构
V1.1__add_demo_data.sql       # 添加演示数据
V1.2__alter_student_add_column.sql # 添加字段
```

**版本规则**：
- 主版本号。次版本号。修订版本号
- 脚本按版本号顺序执行
- 每个脚本只能升级版本，不能降级

### 4.2 历史数据迁移方案

**迁移步骤**：
1. **备份原数据**：迁移前备份原数据库
2. **数据清洗**：清洗不符合新规范的数据
3. **结构迁移**：执行 DDL 脚本创建新表结构
4. **数据迁移**：将旧数据迁移到新表
5. **数据验证**：验证迁移后的数据完整性
6. **应用切换**：切换应用到新数据库

**数据迁移脚本示例**：
```sql
-- 数据迁移：旧表到新表
INSERT INTO new_table (id, name, status, create_time)
SELECT id, name, status, create_time
FROM old_table
WHERE del_flag = '0';
```

### 4.3 数据验证脚本

**数据完整性验证**：
```sql
-- 验证迁移前后数据量一致
SELECT COUNT(*) FROM old_table;
SELECT COUNT(*) FROM new_table WHERE del_flag = '0';

-- 验证主键唯一性
SELECT id, COUNT(*) as cnt FROM new_table GROUP BY id HAVING cnt > 1;

-- 验证外键关联
SELECT n.* FROM new_table n
LEFT JOIN ref_table r ON n.fk_id = r.id
WHERE r.id IS NULL AND n.fk_id IS NOT NULL;
```

**数据质量验证**：
```sql
-- 验证必填字段
SELECT COUNT(*) FROM new_table WHERE required_field IS NULL;

-- 验证数据格式
SELECT COUNT(*) FROM new_table WHERE email NOT REGEXP '^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$';

-- 验证数据范围
SELECT COUNT(*) FROM new_table WHERE age < 0 OR age > 150;
```

### 附录 B：MyBatis XML 映射示例

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
"http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.ruoyi.demo.mapper.DemoStudentMapper">
    
    <resultMap type="DemoStudent" id="DemoStudentResult">
        <id     property="id"        column="id"        />
        <result property="name"      column="name"      />
        <result property="status"    column="status"    />
    </resultMap>
    
    <select id="selectDemoStudentList" parameterType="DemoStudent" resultMap="DemoStudentResult">
        SELECT id, name, status, create_time
        FROM demo_student
        WHERE del_flag = '0'
        <if test="name != null and name != ''">
            AND name LIKE CONCAT('%', #{name}, '%')
        </if>
        <if test="status != null and status != ''">
            AND status = #{status}
        </if>
        ORDER BY create_time DESC
    </select>
    
</mapper>
```
