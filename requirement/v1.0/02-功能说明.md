## 1. 门店门户展示模块

### 1.1 功能描述

门店门户是面向体彩门店顾客的主展示页面，支持9种风格主题切换，展示门店基本信息、公告跑马灯、轮播图、中奖喜报、开奖看板及互动游戏入口。该模块作为门店触屏一体机/电视大屏的核心展示界面，为顾客提供沉浸式体彩信息浏览体验。

### 1.2 功能依赖关系

- 依赖 **门店管理模块** 提供门店配置数据（名称、地址、负责人、电话、营业时间）
- 依赖 **公告管理模块** 提供公告列表（`centralAnnouncements`）
- 依赖 **开奖信息模块** 提供开奖数据（`drawHistory`）
- 依赖 **喜报配置模块** 提供中奖喜报数据（`winnerReports`）
- 依赖 **素材管理模块** 提供轮播图资源（`layoutLibrary`、`carouselLibrary`）
- 依赖后端 `/api/store/:id` 接口获取门店公开配置
- 依赖 `/api/announcements/:storeId` 接口获取公告列表

### 1.3 功能优先级

**高** — 核心展示页面，所有门店互动功能的入口

### 1.4 功能清单

| 编号 | 功能项 | 说明 |
|------|--------|------|
| 1.4.1 | 9种风格主题 | Sports/VIP/Pop/Youth/Neo/Sticker/Guochao/Arcade/Scoreboard |
| 1.4.2 | 门店信息展示 | 名称/地址/负责人/电话/营业时间 |
| 1.4.3 | 公告跑马灯 | 支持多条公告滚动播放，含标签颜色系统 |
| 1.4.4 | 轮播图展示 | 自动轮播，支持图片+标题叠加 |
| 1.4.5 | 中奖喜报 | 展示门店中奖信息列表 |
| 1.4.6 | 开奖看板 | 展示最新开奖号码（红蓝球区分显示） |
| 1.4.7 | 互动游戏入口 | 大乐透选号、顶呱刮抽票、互动游戏中心、大头贴拍照 |
| 1.4.8 | 时钟/日期/运势组件 | 实时时钟、今日吉肖、幸运靓号、主打推荐 |
| 1.4.9 | 布局切换 | 经典流式/左右宣传板/Bento网格 三种布局模式 |
| 1.4.10 | 体彩资讯 | 抓取福建体彩网新闻展示 |

### 1.6 处理逻辑

1. **门店数据加载**：页面初始化时调用 `/api/store/:id` 获取门店配置，若门店不存在返回404
2. **主题渲染**：根据门店 `theme` 字段加载对应风格组件（PortalStyleSports/PortalStyleVIP/PortalStylePop等）
3. **公告过滤**：根据门店 `city` 字段过滤公告，仅显示 `status=true` 且 `scope='ALL'` 或 `scope=城市` 的公告
4. **跑马灯配置**：支持 `duration`（轮播时长）、`interval`（间隔时间）、`speed`（滚动速度）、`rounds`（循环次数）参数
5. **开奖数据展示**：红球使用红色样式，蓝球使用蓝色样式，大乐透前5个为红球后2个为蓝球
6. **Android渠道处理**：当 `channel='android'` 时隐藏二维码，使用全局预设的 `gameConfig`
7. **布局切换**：用户可通过浮动按钮切换经典/宣传板/Bento三种布局

### 1.7 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| 门店不存在 | `/api/store/:id` 返回404 | 显示"门店未找到"提示页面 |
| 公告加载失败 | `/api/announcements/:storeId` 网络异常 | 静默失败，显示空公告列表 |
| 轮播图加载失败 | 图片URL无效或网络超时 | 显示占位图，自动跳过 |
| 开奖数据为空 | `drawHistory.games` 为空数组 | 显示"数据加载中..."占位 |
| 门店已关闭 | `status='closed'` | 显示门店关闭提示 |

## 2. 超级大乐透选号模块

### 2.1 功能描述

超级大乐透选号模块是门店核心互动功能，提供大乐透选号辅助。支持机选（随机生成号码）、自选（手动选号）、套餐模式（预设组合批量生成）。选号结果以动画形式展示，并支持"我的彩票"管理（锁定/修改/删除）和分享长图生成。

### 2.2 功能依赖关系

- 依赖 **门店门户模块** 提供入口导航
- 依赖后端 `/api/track/click` 接口记录点击统计
- 依赖后端 `/api/generate-qr` 接口生成分享二维码
- 依赖 `html2canvas` 库生成分享长图
- 支持实体按键触发（通过 `keydown` 事件监听 Space/Enter/Numpad0）

### 2.3 功能优先级

**高** — 门店核心业务功能

### 2.4 功能清单

| 编号 | 功能项 | 说明 |
|------|--------|------|
| 2.4.1 | 机选模式 | 随机生成5红+2蓝号码，支持单注/批量（5注/10注/20注/50注） |
| 2.4.2 | 自选模式 | 手动点击红球(01-35)/蓝球(01-12)选号 |
| 2.4.3 | 套餐模式 | 按预设配置批量生成多注组合 |
| 2.4.4 | 选号动画 | 4种动画方案（扫描光/呼吸/轮盘/瞬间），Android走快速路径 |
| 2.4.5 | 我的彩票管理 | 锁定/解锁、修改号码、删除彩票 |
| 2.4.6 | 分享长图生成 | html2canvas截取选号结果，叠加门店水印+二维码 |
| 2.4.7 | 实体按键触发 | 支持空格键/回车键/数字键盘0键触发选号 |
| 2.4.8 | 倒计时展示 | 选号过程显示倒计时进度 |
| 2.4.9 | 密度模式切换 | 隐藏入口：5次红球点击+5次黄球点击触发调试面板 |
| 2.4.10 | 价格计算 | 根据红蓝球组合数自动计算投注金额（每注2元） |

### 2.5 字段说明

**选号参数字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| reds | number[] | 是 | 红球号码数组（01-35，不重复，升序） |
| blues | number[] | 是 | 蓝球号码数组（01-12，不重复，升序） |
| count | number | 否 | 批量注数（单式模式） |
| r | number | 否 | 红球数量（复式模式，默认5） |
| b | number | 否 | 蓝球数量（复式模式，默认2） |

**彩票记录字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | number | 是 | 彩票唯一ID（时间戳） |
| type | string | 是 | 彩票类型标签（如"单式5注"） |
| bets | array | 是 | 注数列表，每注含reds和blues |
| price | number | 是 | 总价格（元） |
| tag | string | 是 | 标签：常规/套餐 |
| locked | boolean | 是 | 是否锁定 |

**门店配置字段（选号相关）**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| features.regular | boolean | 否 | 常规选号开关 |
| features.package | boolean | 否 | 套餐选号开关 |
| gameConfig.regulars | array | 否 | 常规选号配置列表 |
| gameConfig.packages | array | 否 | 套餐配置列表 |
| animationDuration | number | 否 | 选号动画时长（ms，默认5000） |
| packageDuration | number | 否 | 套餐动画时长（ms，默认30000） |

### 2.6 处理逻辑

1. **号码生成规则**：红球从01-35中随机选取不重复的5个，蓝球从01-12中随机选取不重复的2个，结果升序排列
2. **价格计算**：`组合数 = C(红球数,5) × C(蓝球数,2)`，`价格 = 组合数 × 2元`
3. **选号动画**：
   - Android平板模式：快速路径，隐藏网格→交换类名→淡入，每注约300ms
   - 桌面模式：React状态驱动的噪点+揭示动画，支持4种方案切换
4. **彩票修改**：锁定状态的彩票不可修改；常规票修改后需匹配门店配置的 `gameConfig.regulars`；套餐票修改必须保持原有红蓝球数量
5. **分享长图**：使用 `html2canvas` 截取分享区域，上传至服务器生成二维码供手机扫码下载
6. **实体按键**：监听 `keydown` 事件，Space/Enter/Numpad0 触发默认选号

### 2.7 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| 选号中重复点击 | `isRolling=true` 时点击 | 忽略点击，不执行 |
| 修改锁定彩票 | 点击已锁定彩票的修改按钮 | 弹窗提示"该彩票已锁定，请先解锁后再修改" |
| 套餐票增加号码 | 套餐票尝试增加红蓝球数量 | 弹窗提示"套餐票无法增加红/蓝球数量" |
| 组合不在配置内 | 修改后红蓝球组合不匹配 `gameConfig` | 弹窗提示"当前组合不在站点配置范围内" |
| 红蓝球数量不足 | 红球<5或蓝球<2 | 弹窗提示"红蓝球数量不足，无法保存（最少5+2）" |
| 分享图生成失败 | html2canvas执行异常 | 弹窗提示生成失败 |

## 3. 顶呱刮抽票模块

### 3.1 功能描述

顶呱刮抽票模块提供体彩顶呱刮即开票的趣味抽选功能。支持四档位（10/20/30/50元），采用CSGO滚轮式动画展示票面，抽选结果随机生成幸运张数。票面数据通过服务端爬虫从国家体彩网抓取并合成。

### 3.2 功能依赖关系

- 依赖后端 `/api/store/:id/scratch` 接口获取票面数据
- 依赖 **爬虫模块** 爬取并合成顶呱刮票面图片
- 依赖后端 `/api/scratch-image/:file` 静态路由提供合成图片
- 支持硬件按键触发（Space/Enter/Numpad0）

### 3.3 功能优先级

**高** — 门店核心业务功能

### 3.4 功能清单

| 编号 | 功能项 | 说明 |
|------|--------|------|
| 3.4.1 | 四档位选择 | 10元/20元/30元/50元面值档位 |
| 3.4.2 | CSGO滚轮式抽票 | 横向滚轮动画，卡片自动跑马灯 |
| 3.4.3 | 推荐张数提示 | 抽选结果展示幸运张数 |
| 3.4.4 | 票面图片预加载 | 切换档位时预解码所有票面图片 |
| 3.4.5 | 定时刷新 | 每60秒静默刷新票面数据（后台暂停） |
| 3.4.6 | 硬件按键支持 | Space/Enter/Numpad0 触发抽选 |
| 3.4.7 | 倒计时返回 | 结果展示10秒后自动返回 |
| 3.4.8 | 票面展示切换 | 支持正面/背面图片切换 |

### 3.5 字段说明

**档位配置字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| tier | number | 是 | 档位面值：10/20/30/50 |
| label | string | 是 | 档位标签（如"10元"） |
| color | string | 是 | 主题色（如"#ec4899"） |
| glow | string | 是 | 发光效果颜色 |
| maxCount | number | 是 | 整本张数（10元60张/20元30张/30元20张/50元20张） |

**票面数据字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 票面唯一标识 |
| name | string | 是 | 票面名称 |
| tier | number | 是 | 面值档位 |
| url | string | 是 | 主展示图URL |
| frontUrl | string | 否 | 正面图URL |
| backUrl | string | 否 | 背面图URL |
| intro | string | 否 | 票面介绍 |
| maxPrize | string | 否 | 最高奖金 |
| type | string | 是 | 图片类型：local-server/external |
| enabled | boolean | 是 | 是否启用 |

**抽选结果字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| winnerImg | object | 是 | 中奖票面对象 |
| luckyNumber | number | 是 | 幸运张数（1-maxCount） |

### 3.6 处理逻辑

1. **数据加载**：初始化时并行请求 `/api/store/:id` 和 `/api/store/:id/scratch`，后续每60秒静默刷新
2. **滚轮动画**：
   - 待机状态：CSS `@keyframes` 实现无缝跑马灯（GPU合成线程，零主线程开销）
   - 抽选状态：先瞬移到起点位置→更新卡片图片→触发CSS transition→滑动到目标位置→弹性吸附
   - 使用 `transitionend` 事件 + `setTimeout` 双重检测确保动画完成
3. **票面预加载**：数据加载后创建 `Image` 对象预解码所有档位图片，切换档位时瞬间显示
4. **结果展示**：随机选择一张票面作为中奖票，随机生成1-`maxCount` 的幸运张数，全屏弹窗展示10秒
5. **硬件按键**：`keydown` 监听 Space/Enter/Numpad0 触发抽选

### 3.7 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| 票面加载失败 | `/api/store/:id/scratch` 网络异常 | 显示"无法加载数据，请检查网络"错误页面 |
| 档位无票面 | `tierImages.length === 0` | 显示"此档位暂无可用票面"空状态 |
| 抽选中重复点击 | `phase='spinning'` 时点击 | 按钮禁用，忽略点击 |
| 图片加载失败 | 票面图片URL无效 | 显示占位图 |
| 票面数据未变化 | 刷新时数据相同 | 跳过更新，避免滚轮重置 |

## 4. 互动游戏模块

### 4.1 功能描述

互动游戏模块包含4款小游戏，为门店顾客提供趣味互动体验。点球大战基于Canvas渲染，支持触屏瞄准+力度控制；小鸟快飞、连连看、消消乐通过iframe嵌入独立HTML实现。

### 4.2 功能依赖关系

- 依赖 **门店门户模块** 提供游戏入口
- 依赖后端 `/api/game-logos` 接口获取游戏Logo
- 点球大战：`src/games/penalty/` 目录下的独立组件（Canvas渲染）
- 小鸟快飞：`/flappy-bird.html` 独立HTML文件（iframe嵌入）
- 连连看：`/lianliankan.html` 独立HTML文件（iframe嵌入）
- 消消乐：`/games/xiaoxiaole/index.html` 独立HTML文件

### 4.3 功能优先级

**中** — 增强互动体验

### 4.4 功能清单

| 编号 | 功能项 | 说明 |
|------|--------|------|
| 4.4.1 | 点球大战 | Canvas渲染，基于FIFA/IFAB规则（5球制+突然死亡） |
| 4.4.2 | 触屏瞄准 | 触摸移动瞄准球门位置 |
| 4.4.3 | 力度控制 | 点击锁定力度条（0-100%） |
| 4.4.4 | 守门员AI | 根据难度等级决定扑救方向 |
| 4.4.5 | 小鸟快飞 | iframe嵌入独立HTML，全屏横屏模式 |
| 4.4.6 | 连连看 | 独立HTML，7种体彩图标（大乐透/号球/排列3/排列5/篮球/足球/乐小星） |

| 4.4.8 | 游戏Logo管理 | 后台可配置各游戏展示Logo |

| key | string | 是 | 游戏标识（lotto/scratch/lianliankan/sticker/xiaoxiaole/flappy） |
| label | string | 是 | 游戏名称 |
| url | string | 是 | Logo图片URL |
| filename | string | 否 | 文件名 |

### 4.6 处理逻辑

**点球大战**：
1. 游戏开始→玩家触摸瞄准（`AIM`阶段）→松手确认瞄准→力度条自动运行（`POWER`阶段）→点击锁定力度→计算弹道（`FLIGHT`阶段）→展示结果（`RESULT`阶段）→下一轮或总结（`SUMMARY`阶段）
2. 弹道计算：根据瞄准坐标和力度值，计算球的飞行轨迹、是否命中球门、是否击中门柱
3. 守门员AI：根据难度等级以不同概率做出正确扑救决策
4. 胜负判定：5轮常规后若平分则进入突然死亡阶段

**连连看**：
1. 7种图标随机填充棋盘，玩家点击两张相同图标若能用不超过3条直线连接则消除
2. 支持提示功能（自动寻找可消除对）和重排功能
3. 计时制，时间耗尽游戏结束

| 错误名 | 说明 |

### 5.6 处理逻辑

4. **保存逻辑**：
   - APK环境：检测 `window.Capacitor`，调用 `Filesystem.writeFile` 保存到外部存储
   - 浏览器环境：创建 `<a>` 标签触发下载
5. **QR分享**：将图片DataURL上传到 `/api/generate-qr`，服务器返回二维码图片

### 6.6 处理逻辑

1. **全国彩种抓取**（`drawHistory.js`）：
   - 优先尝试福建数据源（如有 `fjType`）
   - 降级使用 `webapi.sporttery.cn` 接口，参数 `gameNo` 和 `pageSize`
   - 解析 `lotteryDrawResult` 字段，按空格分割，+号前后分别为主号码和附加号码
2. **福建彩种抓取**（`puppeteerCrawler.js`）：
   - 启动Puppeteer浏览器，导航到 `fjtc.com.cn` 开奖页面
   - 拦截 `data_api/lottery?type=xxx` 的XHR响应
   - 为所有8个彩种类型触发API请求
   - 解析响应数据，提取最新一期开奖结果
3. **公益金抓取**（`crawler.js`）：
   - 全国：调用 `webapi.sporttery.cn/gateway/pwf/getWelfareFundDetailV1.qry`
   - 福建：爬取 `fjtc.com.cn` 首页 `.top-right p` 元素
4. **定时调度**：使用 `node-cron` 在开奖日指定时间段每5分钟执行一次抓取
5. **数据存储**：抓取结果存入SQLite数据库 `draw_history` 表

### 6.7 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| API超时 | sporttery.cn/fjtc.com.cn 响应超时 | 记录错误日志，返回空数据 |
| SSL证书错误 | HTTPS证书验证失败 | 使用 `rejectUnauthorized: false` 绕过 |
| Puppeteer启动失败 | 浏览器启动异常 | 返回fallback数据（空号码） |
| 数据格式异常 | API返回非预期格式 | 使用默认值填充，记录警告 |
| 并发抓取冲突 | `drawHistoryRefreshing=true` | 跳过本次抓取 |
| 解析失败 | 号码格式异常 | 返回空numbers数组 |

## 8. 爬虫与数据源模块

### 8.1 功能描述

### 8.2 功能依赖关系

- 依赖 `puppeteer` 库进行无头浏览器爬取
- 依赖 `axios` 库进行HTTP请求
- 依赖 `cheerio` 库进行HTML解析
- 依赖 `node-cron` 库进行定时任务调度

### 8.3 功能优先级

**高** — 数据基础支撑

### 8.4 功能清单

### 8.6 处理逻辑

**开奖历史爬虫**：
1. 遍历 `NATIONAL_GAMES` 和 `FUJIAN_GAMES` 配置
2. 全国彩种优先尝试福建数据源，降级使用sporttery.cn API
3. 福建彩种使用 `fjtc.com.cn/data_api/lottery` API
4. 并发抓取所有彩种，汇总返回

**公益金爬虫**：
1. 全国数据：调用 `webapi.sporttery.cn/gateway/pwf/getWelfareFundDetailV1.qry`
2. 福建数据：爬取 `fjtc.com.cn` 首页 `.top-right` 元素
3. 日期格式统一为"xxxx年x月x日"

**刮刮乐票面爬虫**：
1. 导航到 `lottery.gov.cn/xdgg/sgty/?p=1&m=面值`
2. 提取列表页所有票面信息（onclick属性解析）
3. 并发抓取详情页（每批4个）
4. 从详情页JS变量 `cpxqV1.dataDetal` 提取图片数据
5. 多图拼接：使用Puppeteer创建HTML页面，flex布局拼接后截图输出JPEG

**运势爬虫**：
1. 遍历12生肖（`m.xzw.com/sxys/{id}/`）和12星座（`m.xzw.com/fortune/{id}/`）
2. 解析HTML提取幸运颜色、幸运数字、今日宜
3. 颜色名称自动映射为HEX值
4. 每次请求间隔400ms避免被封

### 8.7 异常处理

| 异常类型 | 触发条件 | 处理方式 |
|----------|----------|----------|
| API超时 | 请求超过15秒未响应 | 记录错误日志，返回空数据 |
| SSL证书错误 | HTTPS证书验证失败 | 使用 `rejectUnauthorized: false` |
| Puppeteer启动失败 | 浏览器启动异常 | 返回fallback数据 |
| 页面解析失败 | HTML结构变化 | 使用备用选择器或返回默认值 |
| 图片拼接失败 | 图片加载超时或尺寸异常 | 返回单图或空值 |
| 并发限制 | 目标网站限流 | 控制并发数（4个/批）+ 请求间隔 |
| 数据为空 | API返回空列表 | 返回空数组或fallback数据 |
