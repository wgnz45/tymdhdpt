## 1. 界面设计规范

```
┌─────────────────────────────────────────┐
│              顶部导航栏                  │
│         Logo + 菜单 + 用户信息            │

│         │                               │
```

**布局说明**：
| 区域 | 尺寸 | 说明 |

## 3. 交互规范

### 3.1 表单交互规范

**输入框**：
- 获得焦点时显示蓝色边框
- 输入错误时显示红色边框和错误提示
- 必填字段显示红色星号（*）

**下拉选择**：
- 点击展开选项列表
- 支持键盘上下键选择
- 支持输入过滤（如配置）

**单选框/复选框**：
- 点击选项或圆圈/方块均可选中
- 单选框互斥，复选框可多选

**日期选择器**：
- 点击输入框弹出日历
- 支持快捷选择（今天、本周等）
- 支持手动输入

### 3.2 列表交互规范

**排序**：
- 点击列标题可排序
- 支持升序/降序切换
- 当前排序列显示箭头标识

**分页**：
- 默认每页 10 条
- 可切换每页条数（10/20/50/100）
- 支持跳转到指定页码

**批量操作**：
- 勾选复选框选择多行
- 顶部显示已选数量
- 批量操作按钮在选择后激活

### 3.3 弹窗交互规范

**打开弹窗**：
- 居中显示
- 背景遮罩层
- 点击遮罩层可关闭（可配置）

**关闭弹窗**：
- 点击关闭按钮
- 点击遮罩层
- 按 ESC 键
- 点击确定/取消按钮

**表单提交**：
- 校验失败时显示错误提示，不关闭弹窗
- 校验成功且提交成功后关闭弹窗
- 提交中按钮显示 loading 状态并禁用

### 3.4 消息提示规范

**成功提示（Message.success）**：
- 绿色图标
- 自动关闭（3 秒）
- 位置：顶部居中

**错误提示（Message.error）**：
- 红色图标
- 自动关闭（5 秒）
- 位置：顶部居中

**警告提示（Message.warning）**：
- 橙色图标
- 自动关闭（5 秒）
- 位置：顶部居中

**确认对话框（MessageBox.confirm）**：
- 标题 + 内容 + 确定/取消按钮
- 用于删除等危险操作确认

## 4. 响应式设计规范

### 4.1 断点定义

| 断点 | 宽度范围 | 适用设备 |
|------|---------|---------|
| XS | < 576px | 手机竖屏 |
| SM | 576px - 767px | 手机横屏 |
| MD | 768px - 991px | 平板 |
| LG | 992px - 1199px | 小屏电脑 |
| XL | ≥ 1200px | 大屏电脑 |

### 4.2 适配规则

**XS（手机竖屏）**：
- 侧边栏隐藏，使用汉堡菜单
- 表格改为卡片布局
- 表单字段单列显示

**SM/MD（平板）**：
- 侧边栏可折叠
- 表格支持横向滚动
- 表单字段双列显示

**LG/XL（电脑）**：
- 侧边栏展开
- 表格完整显示
- 表单字段三列显示

## 5. 可访问性要求

### 5.1 键盘导航

**Tab 键**：
- 按 Tab 键在可聚焦元素间切换
- 按 Shift+Tab 反向切换

**Enter 键**：
- 在按钮上触发点击
- 在表单中提交表单

**ESC 键**：
- 关闭弹窗
- 取消下拉选择

**方向键**：
- 在下拉选项中上下移动
- 在表格中移动焦点

### 5.2 屏幕阅读器支持

**图片**：
- 所有图标和图片添加 alt 属性
- 装饰性图片 alt 为空

**表单**：
- 每个输入字段关联 label
- 错误提示与字段关联

**表格**：
- 使用 th 元素标记表头
- 添加 scope 属性

### 5.3 颜色对比度

- 正文文字与背景对比度 ≥ 4.5:1
- 大字号文字与背景对比度 ≥ 3:1
- 不单独使用颜色传达信息
