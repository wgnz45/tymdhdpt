# 体育彩票门店互动平台——当前进度说明书（面向客户）

本说明书用更易懂的方式介绍项目目前可演示的能力与正在推进的事项，便于您快速了解现阶段进度。本说明仅代表当前成果，不构成最终交付或上线承诺。

## 亮点速览
- 门店大屏优先：面向福建省内体彩门店电视大屏与展示设备，支持横屏/竖屏双版本
- 内容统一可控：资讯、轮播、喜报目标来源为体彩官方；开发阶段以抓取国家体彩官网与福建省体彩官网模拟官方信源，展示数据为真实数据
- 可演示能力：门店运营门户与多款互动小游戏可直接演示，后续可持续扩展玩法
- 互动提升转化：大屏展示与现场互动结合，提升顾客到店停留时长与参与度
- 合规更稳：模板化填写与审核机制降低不良信息与违禁词风险
- 持续迭代中：号码过滤、后台结构优化、可选模块降级等正在推进

## 1. 项目一句话说明
- 这是一个为线下体彩门店打造的“内容运营门户 + 多款互动小游戏”的系统，用于吸引顾客停留、互动与分享，促进门店到店转化。
- 核心目标：提升门店运营水准，统一体彩内容与信源供给，告别门店物料与宣传方式参差不齐（如实体抽奖设备、电视无内容可播等）。

## 2. 适用场景与使用方式
- 适用场景：福建省内体彩门店电视大屏或其他展示设备为主（横屏/竖屏双版本）。
- 使用方式：通过门店专属链接访问，也可在门店大屏长期展示；支持外接实体“拍拍乐”按键一拍触发互动。
- 项目定位：福建省内体彩门店的门户运营展示屏，手机端展示仍在优化中。

## 3. 已开发（可演示）
### 3.1 门店运营门户（已开发）
- 入口与适配：打开门店专属链接即可进入门户页面，自动适配不同屏幕比例。
- 顶部基础信息：展示门店名称、联系电话、滚动公告，并与门店后台配置同步。公告采用模板化填写。
- 正向提示卡片：展示当前时间与积极导向提示，如“今日幸运数字/推荐互动”，避免负面内容。
- 轮播与视频位：支持官方轮播与门店审核通过的轮播图，预留赛事视频位以便活动期播放。
- 官方资讯区：展示官方/行业/地方资讯列表，标题与日期清晰可读，支持查看详情。
- 门店中奖喜报：展示本门店中奖喜讯图文，来源于店长提交并审核通过的素材。
- 开奖看板：展示大乐透、排列等近期开奖号码、开奖时间与奖池信息；官方数据不可用时展示备用内容，避免空白。
- 小游戏入口：多款互动小游戏入口卡片清晰呈现，未授权游戏自动置灰或隐藏，避免误触。
- 运营价值：门户像一张“门店运营看板”，可持续展示门店亮点与活动，便于大屏驻留与引流。

### 3.2 超级大乐透选号（已开发）
已开发：
- 玩法说明：模拟体彩大乐透选号体验，红球 5 个、蓝球 2 个，号码自动排序且不重复。
- 机选与自选：顾客可一键机选，也可自己点选号码；门店可配置“快捷选号按钮”。
- 套餐选号：支持门店预设套餐组合，一键生成多组号码，便于快速演示或批量分享。
- “我的彩票”：已选号码可加入“我的彩票”，支持锁定、修改、删除，多张一起分享。
- 结果分享：一键生成长图，自动叠加门店水印与门店二维码，便于顾客扫码保存或转发。
- 物理按键：外接按键一拍即机选，屏幕出现倒计时与选号动画，增强现场互动感。
- 使用价值：展示直观、参与简单，适合门店大屏演示与引导体验。
进行中：
- 号码过滤：在摇奖容器内可筛选不喜欢的数字或上一期中奖的数字。

### 3.3 体彩顶呱刮抽票（已开发）
已开发：
- 四档位选择：10/20/30/50 元档位，满足不同价位展示需求。
- 滚轮式抽票：类似“开箱”的滚轮动画，高速滚动后缓慢停下，最终定格到唯一票面。
- 推荐张数：抽中后提示“推荐购买第 N 张”，让顾客有明确行动建议。
- 重复抽取：可反复点击或按键再次抽取，适合门店现场循环演示。
- 票面来源：票面由平台后台上传，门店选择本店可展示票面，保证内容统一合规。
- 物理按键：一键触发滚轮抽取，增强现场参与感。
进行中：
- 号码过滤：用户可筛选掉不喜欢的数字。

### 3.4 平台总控后台（已开发）
已开发：
- 门店管理：创建门店、设置有效期、开关多款互动小游戏权限。
- 内容发布：发布官方资讯与全局轮播素材，统一面向所有门店门户。
- 信源说明：轮播库、文章库、门店喜报列表等目标来源为体彩官方；开发阶段以抓取国家体彩官网与福建省体彩官网模拟官方信源，展示数据为真实数据。
- 审核机制：审核门店上传的轮播图与中奖喜报，支持通过或驳回。
- 信源监控：查看官方数据抓取是否成功，必要时可手动刷新。
- 价值：平台统一管理内容与授权，保障展示内容合规、可控。
进行中：
- 后端数据结构调整：去掉足球相关字段，补齐门店门户专用配置（轮播库、文章库、门店喜报列表等），使数据更贴合现有功能并便于维护。

### 3.5 门店后台（已开发）
已开发（当前界面形态）：
- 基础信息：可设置门店名称、电话、公告，前台实时同步显示。
- 素材提交：上传本店轮播图与中奖喜报，提交后进入审核流程。
- 游戏配置（基础版）：配置大乐透快捷按钮与套餐、顶呱刮可选票面。
- 模板化配置：店长可按多注预设模板填写内容与玩法设置；公告模板示例为“本店购彩者中得超级大乐透{奖级}等奖，奖金{金额}元”。奖级用按钮选择，金额纯数字输入，可选小数并自动换算万元/百万/千万等单位。
- 外设状态：可查看实体按键是否启用。
- 价值：店长可自行更新门店内容与玩法设置，并通过模板化与审核机制降低不良信息与合规风险。
进行中：
- 门店后台 Tab 化重构：分为“基础设置 / 素材管理 / 游戏配置 / 外设 / 账号”五个入口，提升操作清晰度，减少误改与迷路。

### 3.6 数据抓取与兜底（已开发）
已开发：
- 系统自动从官方渠道获取资讯与开奖数据。
- 信源目标为体彩官方；开发阶段以抓取国家体彩官网与福建省体彩官网模拟官方信源，展示数据为真实数据。
- 如遇临时网络问题，自动展示备用内容，避免页面空白或尴尬停摆。
- 对客户而言：页面稳定可用、内容始终可看，是当前重点保障能力。
进行中：
- Puppeteer 可选模块降级验证：确保在不安装浏览器依赖时系统也能正常运行，从而降低部署负担并提升稳定性。

## 5. 客户视角的典型使用流程
1. 平台管理员创建门店并设置有效期与授权。
2. 店长进入门店后台，填写门店名称与电话，按公告模板填写公告内容。
3. 店长上传轮播图与喜报素材，等待平台审核通过。
4. 店长配置大乐透快捷按钮、顶呱刮票面档位。
5. 门店大屏展示门户，顾客浏览资讯、开奖与喜报。
6. 顾客体验大乐透选号与顶呱刮抽票，可扫码保存分享。
7. 店长/平台查看访问与互动的基础数据。

## 6. 数据与报表现状（当前可见）
- 门店可查看：访问量、互动次数、分享次数等基础统计。
- 平台可查看：门店授权状态、有效期、抓取任务成功/降级状态。
- 顾客端不展示任何核奖金额或敏感统计，避免敏感展示并满足合规要求。

## 7. 体验与设计要点（通俗说法）
- 页面字体大、颜色清爽，适合远距离观看。
- 互动按钮响应快，滚轮与选号动画不卡顿。
- 门店大屏横/竖屏自动适配，无需手动调大小；手机端展示仍在优化中。
- 实体按键“接上就能用”，提升现场参与感。

## 8. 名词解释
- 授权：平台为某门店开启或关闭某款互动小游戏的权限。
- 兜底数据：当网络或官方接口异常时，用备用内容补充页面，避免留白。
- 实体按键：外接的物理“拍拍乐”按钮，按一下就能触发互动。
