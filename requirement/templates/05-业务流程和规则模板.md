## 3. 状态流转

### 3.1 状态定义

{适用于有状态机的业务实体，如订单、审批等}

| 状态编码 | 状态名称 | 说明 |
|---------|---------|------|
| 0 | 待提交 | 草稿状态，可修改 |
| 1 | 待审核 | 已提交，等待审核 |
| 2 | 已通过 | 审核通过 |
| 3 | 已驳回 | 审核驳回 |
| 4 | 已取消 | 用户取消 |

### 3.2 状态流转图

```
                    ┌─────────┐
                    │ 待提交  │
                    │  (0)    │
                    └────┬────┘
                         │ 提交
                         │
        ┌────────────────┼────────────────┐
        │                │                │
        v                v                v
   ┌─────────┐     ┌─────────┐     ┌─────────┐
   │ 待审核  │     │ 已取消  │     │  跳过   │
   │  (1)    │     │  (4)    │     │  审核   │
   └────┬────┘     └─────────┘     └─────────┘
        │ 审核
        │
   ┌────┴────┐
   │         │
   v         v
┌─────┐   ┌─────┐
│已通过│   │已驳回│
│ (2) │   │ (3) │
└─────┘   └─────┘
```

### 3.3 状态流转规则

| 当前状态 | 操作 | 目标状态 | 执行角色 | 说明 |
|---------|------|---------|---------|------|
| 待提交 (0) | 提交 | 待审核 (1) | 申请人 | 提交后不可修改 |
| 待提交 (0) | 取消 | 已取消 (4) | 申请人 | 草稿可取消 |
| 待审核 (1) | 通过 | 已通过 (2) | 审核人 | 审核通过 |
| 待审核 (1) | 驳回 | 已驳回 (3) | 审核人 | 审核驳回，可重新提交 |
| 已驳回 (3) | 重新提交 | 待审核 (1) | 申请人 | 修改后重新提交 |
| 已驳回 (3) | 取消 | 已取消 (4) | 申请人 | 放弃申请 |

### 3.4 状态操作权限

| 状态 | 可执行操作 | 不可执行操作 |
|------|-----------|-------------|
| 待提交 | 修改、提交、取消 | 删除 |
| 待审核 | 查看 | 修改、删除 |
| 已通过 | 查看 | 修改、删除 |
| 已驳回 | 查看、重新提交、取消 | 修改 |
| 已取消 | 查看 | 修改、删除、重新提交 |

| 异常类型 | 说明 | 处理层级 |
|---------|------|---------|
| 业务异常 | 违反业务规则 | Service 层抛出 ServiceException |
