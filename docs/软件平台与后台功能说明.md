# 智慧互动屏软件平台与统一管理后台功能说明

本说明基于现有系统功能，对“智慧互动屏软件平台服务”和“统一管理后台服务”的实际能力进行具体阐述，便于方案编制与对外说明。

**一、智慧互动屏软件平台服务**

1.门店门户信息展示模块
支持图片、视频（预留位）、滚动文字、静态公告等多种媒体格式混合展示，支持自定义分屏布局设计，可灵活划分轮播区、开奖看板、本店喜报、互动入口、门店信息区等版块，适配门店大屏展示场景。支持门店独立后台配置门店名称、地址、负责人、电话、门店二维码、欢迎语、营业时间、联系方式、服务项目等基础信息，并实时生效；体彩中心官方公告纳入门户展示。公告内容与轮播图片素材由素材中心统一制定与下发。门店可编辑内容范围有限，宣发内容由中心统一制定，门店可编辑内容通过敏感词库校验，确保内容合规与体彩形象规范一致。

2.互动体验模块
本模块为核心功能模块，聚焦提升购彩趣味性与体验感，包含主要子功能：超级大乐透选号小游戏提供虚拟随机选号、手动选号、套餐票模式、模拟摇奖等功能，机选/自选结合，号码自动去重与排序，包含摇奖/开奖动画，并支持生成分享长图（叠加门店水印与二维码）；顶呱刮抽票模拟体验提供10/20/30/50元档位选择，滚动式抽取幸运票面和幸运数字，模拟刮票体验，无实际资金投注，纯趣味互动，票面图片由总后台素材库统一管理，支持反复抽取与互动体验。后台可对常规/套餐选号、顶呱刮玩法进行开关与参数配置，未授权或关闭时前端入口自动隐藏。

3.实时开奖看板+门店喜报
开奖看板对接国家体彩与福建体彩信源/统一信息发布平台，实时同步超级大乐透、排列三/排列五、7星彩、31选7、36选7、22选5等玩法的最新期号、开奖日期、开奖号码、奖池信息等数据，支持定时自动更新与手动刷新。历史开奖支持全量抓取与前端滚动展示，滚动期数与停留时间在“信源监控”中可配置；安卓Pad端往期布局为“期号/日期一行、球号一行”整体滚动展示，保证可读性与紧凑度。门店喜报支持门店后台手动发布中奖喜讯，通过敏感词库校验后以滚动或列表形式高亮展示，营造幸运氛围。

4.内容管理模块
支持省中心统一制作公益宣传、责任彩票警示、玩法科普、官方活动通知、开奖公告等内容，实时下发至终端门店，支持内容定时推送、循环播放、优先级设置。支持资讯分类管理，按公益类、活动类、公告类、玩法类划分栏目，终端界面清晰规整，购彩者可快速查找所需信息。素材中心统一管理轮播图、活动海报、顶呱刮票面、彩种Logo等资源，支持绑定至开奖信息卡片或轮播区域，并提供图标透明度与背景效果配置，门店不支持上传素材。

**二、统一管理后台服务**

**1. 门店与账号管理**
- 门店创建、停用与信息维护。
- 分配门店后台账号与权限。
- 门店基础信息、欢迎语、跑马灯公告、联系方式、二维码等配置统一管理并实时同步前端。

**2. 内容与素材管理**
- 总站素材库支持图片上传、编辑、删除与分类管理。
- 支持开奖信息图标绑定、Logo透明度配置。
- 轮播素材与海报素材统一发布；门店不支持上传素材。

**3. 信源监控与数据维护**
- 提供国家/省级信源接入状态监控、最近更新时间与异常提示。
- 支持手动强制抓取全链路数据与历史开奖刷新。
- 支持配置“往期轮播期数”“滚动停留时间”等展示参数。

**4. 开奖与玩法配置**
- 支持自动抓取排期与定时更新。
- 支持配置开奖动画时长与套餐生成时长等全局参数。
- 支持手动录入开奖结果与奖池数据，作为异常时兜底。

**5. 互动模块配置**
- 支持大乐透常规/套餐玩法开关与规则配置。
- 支持顶呱刮票面上传、启用/停用与档位配置。
- 控制前端互动入口显示，确保门店合规运营。

**6. 运行状态与基础统计**
- 展示终端在线状态与内容发布记录。
- 可按需扩展互动频次、播放统计与运营报表，为运营优化提供数据支撑。
