## 1. 界面设计规范

### 1.1 整体布局规范

**管理后台布局**（`src/admin/AdminLayout.jsx`）：
- 左侧固定侧边栏：宽度 `w-60`（240px），背景色 `#1e3a5f`
- 侧边栏包含：Logo区域（顶部）、导航菜单（中间可滚动）、用户信息+退出按钮（底部）
- 右侧主内容区：`flex-1` 自适应宽度，背景色 `#f5f7fa`
- 主内容区使用 `<Outlet />` 渲染子路由

**门店门户布局**（`src/pages/StorePortal.jsx`）：
- 全屏响应式设计，背景色 `#fef5f0`
- 顶部红色渐变导航栏（`from-red-600 to-red-500`），包含门店名称和跑马灯公告
- 内容区支持三种布局切换：经典流式、左右宣传板、Bento网格
- 右下角浮动布局切换按钮

## 2. 页面设计（按模块）

### 2.1 门店门户页

**入口路由**：`/#/s/{storeId}`

门店门户提供 9 种风格模板，通过 `PortalStylePop` 组件选择：

| 风格 | 组件文件 | 布局特点 |
|------|----------|----------|
| 经典运动风 | `PortalStyleSports.jsx` | 标准卡片式布局，适合横屏TV |
| 运动风格1 | `PortalStyleSports_Style1.jsx` | 运动风变体，强调赛事信息 |
| 街机风格 | `PortalStyleSportsArcade.jsx` | 复古像素风，游戏感强 |
| 国潮风格 | `PortalStyleSportsGuochao.jsx` | 中国风元素，红色主调 |
| 新锐风格 | `PortalStyleSportsNeo.jsx` | 科技感设计，暗色调 |
| 记分板风格 | `PortalStyleSportsScoreboard.jsx` | 体育记分板样式 |
| 贴纸风格 | `PortalStyleSportsSticker.jsx` | 卡通贴纸风格，年轻化 |
| VIP风格 | `PortalStyleVIP.jsx` | 高端大气，金色点缀 |
| 青年风格 | `PortalStyleYouth.jsx` | 活力色彩，适合年轻群体 |

**门户页通用组件**（`StorePortal.jsx`）：
- **顶部导航栏**：门店名称 + 跑马灯公告（`animate-marquee`）
- **时间组件**：实时时钟（`Clock`图标）+ 日期显示
- **运势组件**：今日吉肖、幸运靓号、主打推荐
- **轮播图**：自动轮播（4秒间隔），支持指示器
- **资讯列表**：体彩资讯，带标签和日期
- **喜报区域**：中奖喜报，带图片和描述
- **开奖区域**：最新开奖号码，红球/蓝球区分显示
- **互动入口**：大乐透选号、顶呱刮两个快捷入口

**布局切换**（右下角浮动按钮）：
- 经典流式（`classic`）：垂直排列，兼容性最优
- 左右宣传板（`billboard`）：左右分屏，适合横向TV
- Bento网格（`bento`）：网格布局，适合电视大屏

### 2.2 大乐透选号页

**入口路由**：`/#/s/{storeId}/lotto`

**页面结构**（`src/pages/Home.jsx`）：

**桌面端布局**（宽度≥1024px）：
- 左侧面板（380px）：玩法按钮区域
- 中央区域：红球网格（35个）+ 蓝球网格（12个）
- 右侧面板（400px）：已选彩票列表

**移动端布局**（宽度<1024px）：
- 顶部：开奖信息
- 中央：选号区域（自适应）
- 底部：操作按钮
- 抽屉式面板：历史记录、已选彩票

**选号区域**：
- 红球：35个球（1-35），网格排列
- 蓝球：12个球（1-12），网格排列
- 球体状态：未选中（半透明）、选中高亮（`ball-red-active`/`ball-blue-active`）、闪烁中（`ball-red-flash`/`ball-blue-flash`）

**选号动画**（4种模式，`animMode`状态）：
- 模式A（Scan light + Pop）：扫描光效 + 弹出
- 模式B（Breathe + Fade-pop）：呼吸灯效 + 渐显
- 模式C（Roulette spotlight）：轮盘聚光灯效果
- 模式D（Instant + container fade）：即时显示 + 容器渐显

**已选彩票列表**：
- 每张彩票显示：类型标签、号码详情（红蓝球圆形标签）、价格
- 操作按钮：编辑、锁定、删除
- 套餐票标记为紫色，常规票标记为蓝色

**分享功能**：
- 点击分享按钮生成彩票图片（`html2canvas`）
- 支持微信企业号推送（`sendWeChatMessage`）
- 支持Webhook推送（`sendWeChatWebhook`）

### 2.3 顶呱刮页

**入口路由**：`/#/s/{storeId}/scratch`

**页面结构**（`src/pages/ScratchCard.jsx`）：

**档位选择**：
- 4个档位按钮：10元、20元、30元、50元
- 每个档位显示：面值、整本张数（10元60张、20元30张、30元20张、50元20张）
- 选中状态：背景渐变色 + 阴影

**轮盘动画区域**：
- 全宽轮盘带（`overflow-hidden`）
- 中心指示器：三角形箭头
- 卡片尺寸：200×260px，间距16px
- 待机状态：CSS `scratchMarqueeKf` 关键帧动画（无限循环）
- 抽选状态：CSS transition 动画（4秒，`cubic-bezier(0.06, 0.6, 0.16, 1)` 缓动）
- 吸附动画：`cubic-bezier(0.34, 1.56, 0.64, 1)` 弹性效果

**抽选按钮**：
- 圆形按钮（130×130px）
- 渐变背景色（跟随档位颜色）
- 状态：空闲（可点击）、抽选中（禁用）、无票面（灰色禁用）

**中奖弹窗**：
- 全屏遮罩（`rgba(0,0,0,0.7)`）
- 放大的票面图片
- 幸运张数显示（大号数字 + 星星装饰）
- 10秒倒计时自动返回（纯DOM更新，零React重渲染）

**档位颜色定义**：

## 3. 交互规范

### 3.1 表单交互

**输入校验**：
- 联系人：姓氏1-2个中文字符 + 称呼模板（正则：`/^[\u4e00-\u9fa5]{1,2}$/`）
- 联系电话：11位数字（正则：`/^\d{11}$/`）
- 密码：至少8位，包含字母和数字
- 实时校验，失焦时触发

**提交反馈**：
- 保存中状态：按钮文字变为"保存中..."，按钮禁用
- 成功提示：绿色背景提示条（`bg-emerald-50 text-emerald-700`），3秒自动消失
- 错误提示：红色背景提示条（`bg-red-50 text-red-700`）
- 信息提示：蓝色背景提示条（`bg-blue-50 text-blue-700`）

### 3.2 列表交互

**搜索**：
- 搜索框带搜索图标（`Search`组件）
- 实时过滤，无需点击搜索按钮
- 支持按多个字段模糊匹配

**分页**：
- 彩票中心支持时间筛选：昨日、今日、本周、本月、今年、全部
- 期号筛选：下拉选择
- 门店筛选（主管理员）：下拉选择

### 3.3 弹窗交互

**确认对话框**（`src/admin/components/ConfirmDialog.jsx`）：
- 标题、消息内容
- 确认按钮（危险操作为红色）
- 取消按钮
- 遮罩层点击关闭

**编辑弹窗**：
- 固定在屏幕中央（`fixed inset-0 z-[999]`）
- 半透明黑色遮罩（`bg-black/40`）
- 顶部标题 + 关闭按钮
- 底部操作栏：取消 + 保存
- 最大高度限制（`max-h-[90vh]`），内容可滚动

### 3.4 消息提示

**Toast消息**（页面内提示）：
- 固定在页面顶部居中
- 滑入动画（`animate-in slide-in-from-top-4`）
- 3秒自动消失
- 类型样式：
  - 成功：`bg-emerald-50 text-emerald-700 border-emerald-100`
  - 错误：`bg-red-50 text-red-700 border-red-100`
  - 警告：`bg-amber-50 text-amber-700 border-amber-100`
  - 信息：`bg-blue-50 text-blue-700 border-blue-100`

### 3.5 动画规范

**轮盘滚动动画**（顶呱刮）：
- 待机：CSS `scratchMarqueeKf` 关键帧，线性无限循环
- 抽选：CSS transition，4秒，`cubic-bezier(0.06, 0.6, 0.16, 1)` 缓动
- 吸附：CSS transition，0.4秒，`cubic-bezier(0.34, 1.56, 0.64, 1)` 弹性缓动
- 中奖高亮：`transform: scale(1.08)` + 边框发光

**选号倒计时动画**（大乐透）：
- 噪声阶段：随机闪烁球（`ball-red-flash`/`ball-blue-flash`）
- 锁定阶段：球体高亮（`ball-red-active`/`ball-blue-active`）
- 弹出效果：`ball-pop-in` 关键帧
- 渐显效果：`ball-fade-in` 关键帧

**页面切换动画**：
- 门户布局切换：`transition-all duration-500`
- 弹窗出现：`scratchFadeIn` 关键帧（0.4秒，从下方滑入）
- 按钮点击：`active:scale-[0.98]` 缩放反馈

**跑马灯动画**（门户公告）：
- CSS `animate-marquee` 关键帧
- 20秒线性无限循环
- 从右向左滚动

## 4. 响应式设计

### 4.1 断点定义

基于 Tailwind CSS 断点：

| 断点 | 宽度 | 设备类型 |
|------|------|----------|
| `sm` | ≥640px | 大屏手机 |
| `md` | ≥768px | 平板竖屏 |
| `lg` | ≥1024px | 平板横屏/小笔记本 |
| `xl` | ≥1280px | 桌面显示器 |
| `2xl` | ≥1536px | 大屏显示器 |

### 4.2 大屏TV适配（16:9）

**基础设计尺寸**：1700×850px

**缩放策略**（`Home.jsx`）：
```
scaleH = availableH / baseHeight
scaleW = availableW / baseWidth
newScale = Math.min(scaleH, scaleW, 1.25)
```

**最小缩放**：0.6（防止内容过小）

**安卓Pad适配**（16:10）：
- 检测条件：Android UA + `Math.min(vw, vh) >= 600`
- 基础宽度：1700px
- 基础高度：根据屏幕比例动态计算（`baseWidthPad / ratioForPad`）
- 缩放上限：1.25

### 4.3 手机适配

**断点**：`vw < 1024px`（`isMobile`状态）

**布局变化**：
- 大乐透选号页：三栏布局变为单栏
- 已选彩票：从右侧面板变为底部抽屉
- 历史记录：从侧边栏变为底部抽屉
- 操作按钮：底部固定栏

**触摸交互**：
- 滑动手势：左滑关闭抽屉（`touchStart`/`touchEnd`检测）
- 最小滑动距离：50px

### 4.4 性能模式

**低性能设备检测**（`src/hooks/usePerformanceMode.js`）：
- Android设备：自动启用低性能模式
- 低内存设备：`navigator.deviceMemory <= 4` 时启用

**低性能模式降级**：
- 禁用 `backdrop-blur`（毛玻璃效果）
- 禁用复杂阴影（`shadow-lg`等）
- 禁用装饰性动画和背景图案
- 简化球体样式（移除圆角）
- 背景色从渐变降级为纯色

**性能配置**（`src/utils/performanceConfig.js`）：
- 轮询间隔：根据设备性能动态调整
- 噪声动画帧间隔：根据设备性能动态调整

## 5. 可访问性要求

### 5.1 键盘导航

- 顶呱刮页支持键盘操作：空格键/回车键/数字0触发抽选
- Tab键在可交互元素间切换
- Enter键激活按钮和链接

### 5.2 屏幕阅读器

- 图标组件提供 `size` 属性控制尺寸
- 图片提供 `alt` 属性（虽然多数为空字符串）
- 按钮使用语义化 `<button>` 标签

### 5.3 颜色对比度

- 主要文字颜色：`text-slate-800`（深灰）在白色背景上
- 次要文字颜色：`text-slate-400`（浅灰）在白色背景上
- 状态颜色（成功/警告/错误）均使用高对比度配色

### 5.4 触摸目标

- 移动端按钮最小尺寸：44×44px
- 列表项高度：至少48px
- 间距：使用 `gap-2`（8px）至 `gap-4`（16px）

### 5.5 自定义滚动条

```css
.custom-scrollbar::-webkit-scrollbar {
    width: 6px;
}
.custom-scrollbar::-webkit-scrollbar-thumb {
    background: rgba(252, 165, 165, 0.5);
    border-radius: 10px;
}
```
