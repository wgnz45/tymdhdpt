## 1. 项目概述

### 1.1 项目背景

- **业务背景**：福建省体育彩票管理中心面向实体体彩门店（便利店、连锁零售等渠道），需要一套数字化互动平台，提升门店运营水准，统一内容与信源供给，改变门店物料与宣传方式参差不齐的现状。
- **立项原因**：传统门店缺乏数字化展示手段，顾客到店停留时间短、参与度低，需要通过"内容运营 + 互动小游戏"模式提升到店转化与留存。
- **核心问题**：
  1. 门店缺乏标准化数字展示窗口，信息公示不统一
  2. 购彩者互动体验单一，缺乏趣味性黏性工具
  3. 省中心无法统一管控全省门店内容发布与运营数据

### 1.2 项目目标

**业务目标**：
- 提升门店到店转化率与顾客停留时长
- 实现全省门店内容的统一发布与合规管控
- 通过互动小游戏增加购彩者黏性与分享率

**技术目标**：
- 支持 6000+ 门店并发访问
- 开奖数据同步延迟控制在官方发布后 5 分钟内
- 系统可用性 ≥ 99.5%
- 前端页面加载时间 < 3 秒

### 1.6 项目约束与假设

**约束条件**：
- 系统底层严禁集成任何资金结算、实际投注或在线交易接口
- 所有互动功能仅限趣味模拟
- 数据来源必须为体彩官方权威信源
- 内容发布需内置敏感词过滤，确保合规

**假设条件**：
- 门店具备电视大屏或安卓 Pad 展示设备
- 设备可访问互联网以获取实时数据
- 省中心有专人负责内容审核与系统管理

## 3. 业务全景

### 3.1 业务范围

**包含的功能**：
- 门店门户信息展示（9种风格主题）
- 超级大乐透模拟选号（机选/自选/套餐）
- 体彩顶呱刮模拟抽票（10/20/30/50元档位）
- 互动小游戏（点球大战、小鸟快飞、连连看、消消乐）
- 中奖大头贴拍照纪念
- 实时开奖信息看板（全国+福建地方彩种）
- 中奖喜报发布与展示
- 统一管理后台（门店/内容/数据/权限管理）
- 数据爬虫与信源监控
- 今日运势（生肖/星座）

**不包含的功能**：
- 实际资金结算与投注
- 在线支付接口
- 彩票出票功能
- 用户注册与个人中心

### 3.2 核心业务流程概览

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 省中心    │───>│ 发布内容  │───>│ 审核通过  │───>│ 全省展示  │
│ 配置系统  │    │ 素材上传  │    │ 敏感词校验│    │ 门店门户  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                       │
┌──────────┐    ┌──────────┐    ┌──────────┐          │
│ 购彩用户  │───>│ 到店互动  │───>│ 参与游戏  │<─────────┘
│ 扫码/大屏 │    │ 浏览门户  │    │ 分享传播  │
└──────────┘    └──────────┘    └──────────┘
```

**流程说明**：
1. 省中心在管理后台配置系统参数、上传素材、发布官方公告
2. 内容经过敏感词校验后发布到全省或指定城市门店
3. 购彩用户到店后通过大屏或手机访问门店门户
4. 用户浏览开奖信息、参与互动游戏、生成分享图片传播
